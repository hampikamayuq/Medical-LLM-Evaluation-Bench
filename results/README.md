# Benchmark results

This directory stores benchmark outputs generated by scripts/run_matrix.py.

## Current status

No external model comparison is committed yet because this public repository does not contain provider API credentials. This is intentional: results should only be published after running the benchmark with explicitly configured models and recording the exact model identifiers and date.

## Synthetic harness smoke test

The internal deterministic adapter is used only to verify that the evaluation pipeline works. It is not a real-model benchmark.

## Real-model matrix

After configuring provider credentials, install the providers extra, copy models.example.json to a local file, set exact model identifiers, and run scripts/run_matrix.py.
